# Avero

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Software developers, engineering teams, and open-source maintainers who need to delegate repository work and inspect the resulting changes during their normal development workflow.

## Product purpose

Avero organizes repository context, agent assignments, execution events, approvals, and engineering results within a workspace. An operator should be able to identify which work is running, what needs a decision, and where to inspect the evidence.

## Capabilities and constraints

The current application provides workspace creation and membership-based access via Clerk and PostgreSQL. The engineering screens use labeled fixtures while repository integrations and execution services are under development. A sample task can be configured and inspected locally. The signed-in workspace flow remains connected to its existing application services.

## Brand commitments

The product name is Avero. The design brief specifies a precise, calm developer workspace with two full themes, an original geometric mark, and a shared component system in the existing Nx repository.

## Accessibility

Target WCAG 2.2 AA for applicable UI. Keep the sidebar, command search, forms, status labels, and technical records usable with a keyboard and on narrow screens.
